# Methabuild — instaladores oficiais

Este repositório público contém somente instaladores, assinaturas criptográficas e manifestos de atualização do **Methabuild**. O código-fonte do aplicativo permanece privado.

Baixe a versão mais recente na página de [Releases](../../releases/latest). Depois da primeira instalação, o próprio Methabuild verifica novas versões ao abrir e pede confirmação antes de atualizar.
